# agrinho2026
projeto para concorrer ao concurso agrinho 2026 
No meu projeto o funcionamento é o seguinte, voçê pode plantar verduras e colher as verduras, também tem uma irrigação IoT e tambem energia solar, você vai plantando e colhendo até conseguir acumular 100kg da colheita e 100% da saúde ambiental através do simulador, com isso conseguimos simular a produção de forma sustentável sem prejudicar o meio ambiente.
